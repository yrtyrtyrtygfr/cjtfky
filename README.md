# 国开无敌自动刷课脚本 使用说明书（v5.0.3 试用卡版）
## 一、脚本简介
专为国家开放大学学习平台打造的浏览器辅助脚本，模拟人工操作、智能挂机刷课，核心功能如下：
- 📂 自动展开课程目录、智能拾取课程链接
- 👆 随机间隔循环点击课程，高度模拟人工操作
- 🎬 视频自动静音播放、多倍速播放，播完自动切课
- ⏸ 支持暂停、继续、自定义最大运行次数
- 📊 实时统计运行时长、播放视频数、点击次数
- 🛡 长效保活机制，后台挂机可持续运行
- 📱 适配深色模式，自动适配屏幕分辨率

## 四、核心功能说明
### 1. 参数设置
- 点击间隔：固定 2~12秒随机（模拟人工，防检测）
- 最大次数：0=无限循环，自定义数值可自动停止
- 视频倍速：支持2x/4x/6x/8x/10x，推荐6x（兼顾效率与稳定性）

### 2. 操作功能
- 一键展开/自动选择：批量识别课程（授权解锁）
- 开始/暂停/停止：灵活控制运行状态，暂停不丢失课程列表
- 手动播放：单独播放当前页面视频，不影响自动流程

### 3. 数据统计与日志
- 实时统计运行时长、视频播放数量、页面点击次数
- 日志最多保存80条，绿色=成功、红色=错误/停止
- 支持日志导出、数据重置

## 六、常见问题解决
**Q1：视频不自动播放？**
1. 确认自动播放开关已开启、账号已授权
2. 检查是否成功拾取有效课程
3. 播放报错时，手动点击一次视频区域，授权浏览器播放权限

**Q2：无法拾取课程元素？**
先一键展开全部目录，再自动拾取；依旧失败则使用手动选择功能。

**Q3：脚本中途停止？**
达到预设最大次数、网络异常、页面课程加载失效均会导致暂停，重启运行即可。

**Q4：面板遮挡页面？**
可拖动面板移动位置，支持折叠最小化、一键关闭。

**Q5：快速停止运行？**
点击停止按钮，或直接按下 **ESC 快捷键** 终止运行。
